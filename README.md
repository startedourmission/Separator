# Toynbee PDF Viewer

인쇄용 PDF 및 이미지 파일을 분석하고 편집하기 위한 웹 기반 도구입니다. 모든 처리는 브라우저상에서 로컬로 진행됩니다.

## 주요 기능

- **CMYK 분판 분석**: C, M, Y, K 각 채널별 온/오프 및 별색(Spot Color) 감지
- **잉크량 분석**: 마우스 위치의 CMYK + 모든 별색을 합산한 실시간 TAC(Total Area Coverage) 및 채널별 비율 표시
- **잉크량 초과 표시**: `300% 초과` / `350% 초과` 버튼으로 CMYK와 모든 별색 합계가 기준을 넘는 위치를 빨간색으로 표시합니다. 같은 버튼을 다시 누르면 해제되며, 좌우 비교의 각 화면에도 해당 데이터로 적용됩니다. 화면 표시용이며 OCR·재단선 분석·PDF 이미지 내보내기에는 경고색을 넣지 않습니다.
- **오버프린트 미리보기**: 기본 켜짐. PDF의 오버프린트 설정을 화면, 잉크량 분석 및 이미지 내보내기에 반영하며, 끄면 녹아웃 화면을 표시합니다. 준비된 두 화면은 즉시 전환합니다.
- **좌우 비교**: 왼쪽 패널의 오버프린트 미리보기 옆 `좌우 비교`를 켜고 페이지 위 핸들을 움직이면 왼쪽 녹아웃·오른쪽 오버프린트를 비교합니다. 커서 잉크량은 해당 쪽의 데이터를 표시하고, 문서 전체 분석과 내보내기는 기존 오버프린트 체크박스 설정을 따릅니다.
- **표지 계산기**: PDF 로드 후 첫 페이지의 재단선을 자동 분석하여 책등, 날개, 펼침면 크기 계산. 재단선을 찾지 못하면 TrimBox 크기를 표시하며 수동 입력도 가능합니다.
- **분석 도구**: 드래그 영역의 텍스트 스캔(OCR) 및 바코드/QR 분석
- **워터마크**: 다수의 텍스트를 일괄 적용한 개별 PDF 및 압축 파일 생성
- **고해상도 렌더링**: 최대 1200 DPI 수준의 정밀한 렌더링 지원

## 실행 방법

1. 의존성 설치:
   ```bash
   npm install
   ```
2. 로컬 서버 실행:
   ```bash
   npm start
   ```
3. 웹 브라우저에서 `localhost:5000` (또는 지정된 포트) 접속

## 검증

- `npm test`: 별색 합성, 분판 토글, 중복 렌더 방지 및 메모리 제한 캐시 회귀 테스트.
- `npm run test:browser`: Playwright Chromium에서 실제 WASM 렌더링, 오버프린트 ON/OFF, 잉크량 및 RGB 출력 검증. 먼저 `npx playwright install chromium`을 실행하거나 `BROWSER_EXECUTABLE`로 실행 파일 경로를 지정합니다. 사이트가 사용하는 CDN 라이브러리를 읽을 수 있어야 합니다.
- 루트에 `higs_cover.pdf`가 있으면 보고된 세 누락 영역도 검증합니다. 결과는 `_docs/overprint-verification/`에 저장합니다.
- `OVERPRINT_REGRESSION_PDF=/path/to/0916.pdf npm run test:browser`로 0916 수정 표지의 2페이지 CMY 오류도 검증합니다. 합성한 최소 재현 PDF는 해당 파일 없이도 항상 검사합니다.

화면에 보이는 페이지는 녹아웃·오버프린트 두 버전을 미리 준비하고 완성된 캔버스를 재사용합니다. 준비가 끝나면 체크박스 전환도 픽셀 재합성 없이 즉시 화면을 바꿉니다. 핸들 이동은 CSS로 표시 경계만 변경하므로 PDF 재렌더링이 없습니다. 설정별 잉크판 캐시는 512 MiB 한도 내에서 최근 사용한 페이지를 유지하며, 문서·화질 변경 시 비웁니다. 캐시에서 빠진 페이지는 다시 준비합니다.

## 화면 색과 성능

- `JapanColor2001Coated.icc` → sRGB를 LittleCMS로 변환합니다. 상대적 색도계 + 검정점 보정을 사용하며, 용지색 시뮬레이션은 하지 않습니다. 기존 대표색 보간/K 감쇠 공식은 제거했습니다. 현재 화면의 출력 프로파일은 이 파일로 고정되며, 다른 PDF OutputIntent를 자동으로 화면 프로파일로 선택하는 기능은 없습니다.
- GPU는 실제 ICC에서 추출한 33⁴ 격자를 선형 광량 공간에서 보간합니다. 색역 밖 값을 보간 전에 자르지 않습니다. GPU 미지원/컨텍스트 손실 시 같은 ICC의 CPU 변환으로 대체합니다. 라이브러리는 `vendor/lcms`에 포함되어 추가 CDN이 필요 없습니다.
- 별색은 페이지의 Separation/DeviceN 대체 CMYK를 Ghostscript에서 받아 프로세스 잉크와 합성합니다. 이름별 RGB 표/겹친 픽셀의 평균색보다 문서 정의를 우선합니다. 이 방식은 tiffsep의 대체 잉크 모델이며, 특수 잉크나 비선형 tint transform의 물리적 인쇄 결과까지 보장하지 않습니다.
- 화면용 캔버스는 표시 배율·기기 픽셀 비율에 맞추고, 확대 시 필요하면 원본 분판에서 다시 그립니다. 잉크량, OCR/바코드, 재단선 분석에는 원본 DPI를 사용합니다. PDF 이미지 내보내기는 지정한 DPI로 별도 렌더합니다.
- 분판 변경은 보이는 화면을 먼저 갱신하고, 비교 모드가 꺼져 있으면 반대 화면 갱신을 유휴 시간으로 미룹니다. GPU 소스 캐시는 256 MiB 한도이며, 숨겨진 화면의 임시 업로드는 보이는 화면 캐시를 밀어내지 않습니다. 문서/화질 변경 때 해제합니다.
- Ghostscript의 격리된 녹아웃 투명 그룹에서 오버프린트 K100에 가짜 CMY가 생기는 문제를 우회합니다. 내부가 모두 불투명한 K100 벡터 경로임을 검증한 그룹만 렌더링 사본에서 불필요한 내부 녹아웃 설정을 해제합니다. 격리·오버프린트 설정과 원본 PDF는 유지하며, 혼합 색상·반투명·이미지·텍스트 등 검증 범위 밖의 그룹에는 적용하지 않습니다. 로드 시 한 번 준비한 사본을 화면·잉크량 스캔·이미지 내보내기에서 재사용합니다.
- `npm test`에 독립 Pillow/ImageCms 기준 패치 및 PDF 별색 대체값 검증이 포함됩니다. 브라우저 테스트는 GPU 색 오차, CPU 대체 경로, 분판 클릭, 원본 분석 해상도와 오버프린트 즉시 전환을 확인합니다. Acrobat과 비교할 때는 시뮬레이션 프로파일과 용지색/검정 잉크 설정도 맞춰야 합니다.

## 구현 예정

- **DIC 별색 지원**: DIC 컬러 가이드 RGB 근사값 매핑 추가 (DIC 285, 717, 2193, 2228, 2925, 3534, 3538, 3556 등)
- **Worker PDF 전송 최적화**: 매 페이지 렌더 시 PDF 전체를 worker로 복사 전송하는 구조를 1회 전송으로 개선

## 기술 사양

- **Core**: WebAssembly 기반 Ghostscript (분판 렌더링)
- **PDF**: pdf.js (뷰어), pdf-lib (워터마크 수정)
- **Processing**: Tesseract.js (OCR), ZXing (Barcode/QR)
- **Performance**: Virtual Scrolling 기반 대용량 PDF 처리
